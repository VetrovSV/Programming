## Кратко

Курс даёт практические навыки программирования и работы с инструментами, необходимыми для реализации классических ML‑пайплайнов и прототипирования моделей. Основной язык — Python; акцент на практических навыках и защите работ.

## Цели курса

* Научить эффективно использовать Python‑экосистему для задач МО и подготовки данных.
* Дать навыки быстрого прототипирования модели и развёртывания простого интерфейса.

## Ожидаемые результаты обучения

Вы сможете:

* понимать основы Python, его особенности; создавать модули, классы, тесты;
* быстро прототипировать интерфейсы пользователя (Gradio) и API (FastAPI);
* контейнеризовать приложение и подготовить инструкцию по запуску *(опционально, при наличии времени)*.


См. также курс [Введение в проектирование интеллектуальных систем](https://github.com/ivtipm/ML/blob/main/plans/AI_intro_2025/2025_ML_intro.md)

### Практика

1. Создайте сервер:  
- чётный вариант: сервер с пользовательским интерфейсом на Gradio или на аналогичном фреймворке (по согласованию с преподавателем)

2. Создайте отдельный класс с методом, который принимает numpy массив и возвращает либо значение типа float либо значение типа int

   Функция должна имитировать применение модели МО:  
- если `int ( (вариант + 1) / 2 )` — чётное число  → логистическая регрессия;

  Коэффициенты можно записать вручную как числовые литералы.  
  Для вычислений используйте массивы и методы из numpy.

   Используйте оператор assert или специальный тестовый фреимворк

Документировать код и функции не обязательно, но оставьте для каждой функции документирующий комментарий.
